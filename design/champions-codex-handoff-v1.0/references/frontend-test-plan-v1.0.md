# React UI・状態管理 受け入れ試験仕様 v1.0

- フェーズ: 設計のみ / 実装試験未実施
- 観点: UI v0.5との一致、状態分離、通常⇄TOP50、API/保存前後の整合性、スマホ操作
- 手法（実装時）: Vitest（store, selectors, formatters）+ React Testing Library（コンポーネント）+ Playwright（PC/モバイルE2E）。ルール実測照合は別のエンジン試験。

| ID | 区分 | 操作 / 入力 | 期待結果 |

## 品質ゲート

- P0: FE-11〜16, FE-25〜33, FE-35〜36, FE-37〜43を本番導入前に必須合格。
- 機能数値の正確性: エンジンv1.2のゴールデンテストと独立して実施。
- API/DB認可と共有のセキュリティ: 次のAPI連携設計・DB最終統合と共通のE2Eテストを定義。
- 未収録データ・未実装効果については、推測値を成功表示しない。

# U-06：共有URL機能を初期リリース対象から除外 — 確定設計 v1.7

- 決定日: 2026-10-23
- ステータス: **製品仕様として確定**／設計差分は本書を正本とする／実装なし
- 優先順位: 本書 > 過去の「共有を実装する」と書かれた要求・画面・Frontend・API・DB・Codex契約
- 変更理由: 共有機能は製品の必須要件ではない。過去TOP50の90日再現を目的とする保管・再公開を行わず、主要機能に集中する。

## 1. インスコープ / アウトオブスコープ

| 機能 | 初期リリース | 動作 |
|---|---|---|
| 通常ダメージ計算 | 対応 | 匿名利用可 |
| TOP50まとめ計算 | 対応 | 匿名利用可。公開中のTOP50で計算 |
| 詳細から通常計算への設定転写 | 対応 | ブラウザ内の操作。共有URLとは独立 |
| Google OAuth／メールMagic Link | 対応 | 計算だけならログイン不要 |
| 個人用保存・読込・削除・端末間同期 | 対応 | 本人のみ。サーバー認可とRLS |
| 共有リンク生成・コピー | **対象外** | 画面から削除 |
| 共有リンク閲覧画面 | **対象外** | 公開トークンによる参照を提供しない |
| 過去TOP50を共有のために90日保持 | **対象外** | 履歴公開・90日再現保証なし |
| 計算結果画像の自動SNS投稿／公開短縮URL | **対象外** | 別件で再検討するまで提供しない |

本決定は「共有機能を将来絶対に実装しない」を意味しない。将来必要になれば新たな利用条件調査・仕様決定を経て別フェーズで検討する。**Codexに将来用の未使用共有テーブルやAPIを先行実装させない**。

## 2. 前回の決定 U-03〜U-05 の効力

- U-03（共有発行はログイン必須・匿名閲覧可）: **初期リリースでは適用しない／撤回（superseded）**。
- U-04（共有URL有効期限90日）: **初期リリースでは適用しない／撤回**。90日という値をDB保持や個人保存に流用しない。
- U-05（共有時点のTOP50を90日再現）: **初期リリースでは適用しない／撤回**。過去の統計情報を共有・公開する機能を前提としない。
- U-01（合法な性格ID）、U-02（Google＋Magic Link）、P0-01（毎時検知）、P0-02（保存DTO統一）は**有効のまま**。

## 3. UI / React / 状態管理

1. UI v0.5は操作・配置の基本正本として残す。ただし**共有関連のボタン、メニュー、ダイアログ、説明文は表示しない**。画面の残りを不必要に再設計しない。
2. `ShareActions`, `SharedCalculationPage`, `app/shared/[token]`, `app/share/[token]` 等は初期リリースのコンポーネント／ページ構成から除く。既存資料内の`/shared`と`/share`の表記ゆれを実装しないことで解消する。
3. 匿名ユーザーは計算条件をブラウザ内で編集できる。認証後の「明示保存」動作は維持する。ログインそのものを保存トリガーにしない。
4. TOP50詳細内の技／戦闘条件はローカルドラフト、個別防御型はTOP50セッションに反映、通常計算への転写は従来どおり。
5. 一時ドラフト、表示用フィルター、スクロール位置、ダメージ計算結果はサーバーへ保存しない。

## 4. API / OpenAPI / 共通DTO

- **削除対象エンドポイント**: `POST /api/v1/shares`, `GET /api/v1/shares/{token}`, `DELETE /api/v1/shares/by-id/{id}` および共有専用の追加API。これらを実装・公開しない。
- **維持対象**: `GET /api/v1/bootstrap`, `GET /api/v1/rankings/active`, 個人保存用`/api/v1/calculations`のCRUD、認証の安全な連携。
- **条件付き維持**: `GET /api/v1/rankings/snapshots/{snapshotId}` は、開いているTOP50セッションの固定や個人保存の再読込に必要な場合にのみ提供。履歴公開API・大量アーカイブ代替として提供しない。保存許諾と保持期間に従い期限切れを返せる設計とする。
- `SavedInputSnapshot` の正本は `{ payloadSchemaVersion: 1, mode, input }` とし、**個人保存専用**に利用する。`SharedCalculationDTO`, `ShareCreateRequest`, `ShareResponse`, `SHARE_EXPIRED`, `SHARE_REVOKED` といった共有固有定義は実装対象外。
- 個人保存の「外部TOP50参照がすでに使えない」場合は、`SNAPSHOT_EXPIRED` または `VERSION_INCOMPATIBLE` のエラー／警告を表示し、**黙って最新TOP50へ置換しない**。最新版への移行はユーザーの明示確認を必要とする。長期再現保証は別途確定していない。

## 5. DB / RLS / ランキング保持

- `shared_calculations` テーブル、公開トークンのhash検索、公開共有用の権限・RPC・失効・90日清掃ジョブは**初期スキーマに含めない**。
- `saved_calculations` は保持し、`owner_id` とRLS/GRANTにより本人だけが閲覧・変更・削除できるようにする。
- `api_idempotency_keys` を維持するかは個人保存の冪等性要件で判断し、共有トークンの再発行・暗号化応答保管を理由に残さない。
- ランキングの`ranking_publications`、`active_publication`、`ranking_snapshots`等は**最新データの表示・段階的更新・障害時ロールバック**のために引き続き必要。共有のための90日保存は不要。
- 何世代をどれだけ保持するかは、データ提供元の利用条件・ロールバックの運用要件・個人保存の復元可否の整合を確認して別途定める。**共有削除＝履歴保持ゼロ**とは解釈しない。
- 原子公開、毎時更新確認、当日成功後の外部確認停止、旧正常版保持は不変。

## 6. 外部データと権利

1. 過去90日分の統計の公衆向け再公開は初期要件から消えるので、その機能に特化した許諾確認は公開ゲートから除去できる。
2. **残る必須確認**: メインAPI/統計のアプリ内利用、必要なキャッシュ、出典表示、利用上限、適用される条件の現行版。公式ゲームの順位と同一と断定するには別途照合が必要。
3. ポケモンの画像・ロゴ等の権利はAPIの利用条件とは独立して確認する。APIの利用許可が全IP利用許諾を意味するわけではない。
4. 許諾未確認のデータを使って「過去ランキング閲覧サービス」や外部公開DBを構成してはならない。

## 7. Codex向け受入れ条件（設計上のテスト指定）

| ID | 条件 | 期待結果 |
|---|---|---|
| SCOPE-01 | ゲストが通常計算／TOP50計算を開く | ログインなしで計算可能 |
| SCOPE-02 | 未ログインで個人保存を押す | 認証へ誘導、編集中の内容を維持 |
| SCOPE-03 | ログイン後に保存と別端末で読込 | 本人の計算入力を復元 |
| SCOPE-04 | 他人のsaved IDへアクセス | 権限拒否。他人の設定が漏れない |
| SCOPE-05 | 通常／TOP50の画面で共有UIを探す | 共有生成・コピー・共有ダイアログが存在しない |
| SCOPE-06 | `/api/v1/shares` を呼ぶ | 共有APIが存在せず、データや有効なトークンを生成しない |
| SCOPE-07 | `/share/{token}`・`/shared/{token}` を開く | 共有データを返さない（通常404等） |
| SCOPE-08 | 初期DBを調べる | `shared_calculations` と共有専用ポリシーがない |
| SCOPE-09 | ランキングが正常更新される | singles/doubles原子公開・旧版保持条件を満たす |
| SCOPE-10 | 個人保存が参照する過去snapshotが削除済み | 理由を表示し、無言で現行TOP50へ差替えない |
| SCOPE-11 | TOP50詳細から通常計算へ遷移 | 詳細の条件を引き継ぐ。共有ルートに依存しない |
| SCOPE-12 | ログインした直後 | 明示保存前に計算設定を勝手にDB保存しない |

この表は **将来実装時の受入れテスト設計** であり、実行結果ではない。

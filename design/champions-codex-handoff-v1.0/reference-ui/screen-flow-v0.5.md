# ChampionCalc 画面遷移図 v0.5

## 1. 画面間遷移

```mermaid
flowchart TD
    START[アクセス] --> NORMAL[通常ダメージ計算]
    NORMAL <-->|モード切り替え| TOP[TOP50まとめ計算]
    NORMAL --> SWAP[攻守を入れ替え]
    SWAP --> NORMAL
    TOP --> RANK[50匹の比較表]
    RANK -->|行 / 技のセルを選択| DETAIL[TOP50詳細]
    DETAIL -->|閉じる| RANK
    DETAIL -->|通常計算へ| TRANSFER[攻撃側の型・防御側の型・技・詳細条件を引き継ぐ]
    TRANSFER --> NORMAL
    NORMAL --> SAVEP[保存 / 共有]
    TOP --> SAVEP
    SAVEP --> LOGIN[認証・共有機能は本番実装]
    NORMAL --> SAVED[保存した計算]
    TOP --> SAVED
    SAVED --> NORMAL
    SAVED --> TOP
```

## 2. TOP50詳細の状態遷移

```mermaid
flowchart TD
    A[TOP50一覧] -->|詳細を開く| B[共通戦闘条件をコピー]
    B --> C[詳細画面]
    C --> D[ポケモンの型編集]
    C --> E[詳細内の技を変更]
    C --> F[詳細内の戦闘条件を変更]
    D --> C
    E --> C
    F --> C
    C -->|閉じる| G[詳細の技・戦闘条件を破棄]
    G --> A
    C -->|通常計算へ| H[詳細状態を通常計算に転写]
    H --> I[通常ダメージ計算]
```

**編集状態に関する例外**：TOP50詳細で変更した防御側のポケモンの型は、一覧のその個体のカスタム型として保持する。一時的なのは詳細内の技と戦闘条件。通常計算に遷移した場合は、その技と戦闘条件も引き継ぐ。

## 3. スマホのTOP50操作

```mermaid
flowchart TD
    A[TOP50表示] --> B[コンパクトな50匹一覧]
    A --> C[攻撃側設定を開く]
    C --> D[攻撃側・4技・共通戦闘条件を編集]
    D --> B
    B --> E[4技固定タブを切り替え]
    E --> B
    B --> F[検索・絞り込みを開く]
    F --> B
    B --> G[個体行をタップ]
    G --> H[詳細ボトムシート]
    H -->|閉じる| B
    H -->|通常計算へ| I[通常計算]
```

## 4. 入力コンポーネントの状態遷移

```mermaid
flowchart TD
    A[入力欄にフォーカス / 右端の▾] --> B[候補表示]
    B --> C{種類は?}
    C -->|ポケモン / 特性| D[許可された候補のみ確定]
    C -->|技| E[習得技候補 / 入力時は習得外の既知技]
    C -->|持ち物| F[候補 または 自由入力]
    D --> G[画面を更新]
    E --> G
    F --> G
```

## 5. 画面上の名称変更

- `乱数・確率詳細` → `詳細`
- `最短撃破` を撤去
- `16通りの乱数`、独立した `撃破判定` 項目を詳細から撤去
- `周囲のポケモンを攻撃する範囲技` → `範囲技`
- `型を編集` は独立操作として設けず、詳細画面内の編集フォームに統合

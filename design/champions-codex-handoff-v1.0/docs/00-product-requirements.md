# 00 — 製品要件（統合版）

## 製品と範囲

- Pokémon Champions 専用、PC/スマホ対応Webアプリ。シングルとダブル両対応。Lv.50固定。
- 通常計算：攻撃1匹→防御1匹、選択技最大4つ。攻守の入替が可能。
- TOP50まとめ計算：その形式のゲーム内Battle Data由来TOP50を防御側として、最大4技×50匹＝最大200組を評価。4匹同時に操作するバトルシミュレーターではない。
- サインインなしで計算できる。保存・読み込み・編集・削除・端末間同期はログイン時のみ。Google OAuth＋メールMagic Link（パスワード式は初期対象外）。
- **共有リンク、共有ページ、共有専用API/DB、90日再現保持はすべて初期スコープ外**。旧U-03〜05はU-06により撤回。

## 入力

- 能力ポイントは6能力それぞれ整数0〜32、合計66以下。能力値との双方向編集・±1ステッパー。成立しない実数値はポイント`?`を表示し、有効な計算結果を出さない。
- 性格倍率は0.9 / 1.0 / 1.1の見た目を維持し、非HPの5能力の**合法な単一性格ベクトル**を内部で持つ。複数候補があれば選択を求め、他能力へ影響する場合は明示。ゲーム本体でのStat Alignmentとの対応は検証ゲート。
- 物理/特殊切替で入力項目は変わっても、内部の全6能力ポイントと全5能力倍率は維持。
- 技検索の通常候補は習得技。既知の習得外技も名前入力で指定可能（合法習得技と誤表示しない）。未登録技や未実装技は推測計算しない。
- 特性は選んだポケモンの合法な候補のみ。持ち物は自由入力可能、登録済みは効果を表示。未解決の持ち物は効果不明とし、計算の妥当性を保証しない。
- 技のタイプ/分類/威力/対象/効果説明と追加効果率（判明しているもの）を表示。天候、フィールド、急所、壁、能力ランク、状態異常、必要な味方補助条件を指定可能。

## 出力とUI

- 整数ダメージ範囲、割合（モバイルにも常時表示）、左側に残HPを表示し右側から減少するHPバー、具体的なn発と条件付き撃破確率。`3発以上`はフィルターだけの表現、結果は`確定4発`・`乱数5発`等の具体的なnを使う。
- 16通りの個別ダメージの一覧はUIに表示しない（計算エンジン内部で利用）。冗長な最短撃破行を置かない。計算不可/未検証を明示。
- TOP50：PCでは4技分のコンパクトな一覧、スマホでは固定技タブ、検索・フィルター、詳細ボトムシート。詳細では個別型編集、技・条件の一時比較、通常計算へ引き継ぎ。
- TOP50防御側は実測joint distributionが取れた場合のみ`実測代表型`。カテゴリ別トップ要素の合成は`推定代表型`。出典と更新データ時刻の区別を表示。

## 非機能・品質

- 通常とTOP50は純粋計算コア1つ。200組計算のUI操作性を端末条件付きで測定（3秒目標、ハードウェア固定の絶対的な保証ではない）。
- 入力変更中の計算結果の取り違えを防ぐ。DBはRLSとAPI認可。外部サービス認証情報はサーバーのみ。
- ブラウザでのエラーを人が理解できる表示とし、未知の計算効果は`unsupported`、入力不足`missingContext`、入力不正`invalid`。
- P0-05のゲーム内順位との比較・P0-06の実機整数ダメージ照合・採用データの権利/画像権利の確認を本番公開前の必須ゲートとする。

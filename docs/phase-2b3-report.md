## 分母と評価層

次の数値を混ぜない。

1. **データ参照解決**: 推定代表型1件を1行とし、各形式50行を分母とする。候補辞書の存在、型・ポイント・性格の構造を確認するだけで、収録・意味・ゲーム能力値の承認ではない。
2. **候補ルール対応**: 現在の5技モデル/3効果定義に名前で対応するか。実マスターとの結合は未実装。既存3効果は今回の5技で防御側が持つ場合outgoing_onlyとして扱えるが、その他の効果を中立と推測しない。
3. **本番実行可能**: 未承認ルール拒否と未結合実カタログによる適格性。実データをfixtureへ昇格して数値成功率を測る方法は採らない。
4. **ゲーム証跡**: 対象行について利用できる自分たちのL3証跡の保有率。0%は「ゲームと一致する確率が0%」という意味ではない。実際のゲーム精度は未測定。

フォーム別実行ルール結合0件/本番適格0件は、実装点検と全体ゲートによる判定であり、50回の製品計算を試した結果ではない。合成fixtureだけでproductionがRULES_NOT_APPROVEDを返すことを再確認した。実データの計算実行回数は0。
